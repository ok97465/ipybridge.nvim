# AGENTS Instructions

## Documentation and Comments
- Perform coding, comments, and README.md edits in English, but always report results in Korean.
- Write Python docstrings in Google style.
  - Do not include type hints inside docstrings.
  - Put type hints directly in parameter definitions.
  - Omit the `Args` section when parameters are trivial or self-explanatory.
- Write Lua function docstrings.
  - Omit parameter listings when parameters are trivial or self-explanatory.
- When modifying code, review file header comments and update them if needed.
- After edits, review comments in modified code and improve them as needed.

## Testing
- After code changes, always run tests.
- When a valid test case can be created, add a test.
  - Do not add tests that are not effective.
